Programa de linha de comando em Python para gerenciar tarefas: criar, listar, 
marcar como feita e apagar, as tarefas ficam salvas em um arquivo JSON, então 
não se perdem ao fechar o programa, ao marcar uma tarefa como feita, o programa 
busca uma frase motivacional em uma API externa.

Este foi meu primeiro projeto de programação, feito estudando Python por conta própria.

O que aprendi fazendo este projeto
- Como salvar e ler dados em arquivos JSON
- Como fazer requisições a APIs externas com a biblioteca requests
- Tratamento de erros com try/except
